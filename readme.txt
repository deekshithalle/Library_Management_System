# 📚 Library Management System

A simple Library Management System built using HTML, CSS, and JavaScript.

## Features

- Add Books
- Delete Books
- View Available Books
- Dashboard with Statistics

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Future Enhancements

- Search Books
- Issue & Return Books
- Fine Calculation
- Local Storage

- Dark Mode
